# 色彩検定UC級 暗記カード

色彩検定UC級の弱点暗記用Webアプリ＆問題データ管理リポジトリです。

## ファイル一覧
- **`index.html`**：暗記カードWebアプリ本体（ダブルクリックでブラウザで開くだけで動作します。同僚への配布もこのファイルを渡すだけでOKです）
- **`sample-uc-questions.xlsx`**：GridCraft / Excel 用の問題データ（列幅・折り返し設定済み。そのまま `index.html` にドラッグ＆ドロップして読み込めます）
- **`sample-uc-questions.csv`**：CSV版の問題データ
- **`GEMINI.md`**：AI（Antigravity）用の作業引き継ぎメモ
