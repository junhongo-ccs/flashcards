# 色彩検定UC級 暗記カード

色彩検定UC級（色のユニバーサルデザイン級）の受験対策・弱点暗記用のWebアプリです。  
サーバー不要で、`index.html` をブラウザで開くだけでそのまま使えます。

---

## 1. はじめ方（一番かんたんな使い方）

1. フォルダ内の **`index.html`** をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開きます。
2. 自分の問題データ（Excel または CSV）を読み込ませて暗記カードとして学習できます。

---

## 2. 基本の操作方法

### カードをめくる・移動する
| 操作 | マウス / タッチ | キーボード |
| :--- | :--- | :--- |
| **解答を表示する（裏返す）** | カード部分をクリック | `Space`（スペースキー） |
| **次の問題へ進む** | 「次へ →」ボタン | `→`（右矢印キー） |
| **前の問題へ戻る** | 「← 前へ」ボタン | `←`（左矢印キー） |

### 画面上部のメニュー
- **カテゴリ選択（左上）**：「すべてのカテゴリ」または特定の分野だけに絞り込んで出題できます。
- **`[ 問題 | 一覧 ]` スイッチ（右上）**：
  - **問題**：1問ずつ暗記カード形式で学習する通常モードです。
  - **一覧**：すべての問題と解答を一覧で確認するモードです。一覧のカードをクリックすると、その問題のカード表示へ直接ジャンプします。

---

## 3. 自分の問題データ（Excel / CSV）を作って読み込む方法

自分が覚えたい弱点だけをまとめた Excel（`.xlsx`）や CSV（`.csv`）を読み込ませることができます。

### Excel / CSV の作り方（3列構成）
1行目をヘッダーにして、以下の3列で入力してください（1行＝1問）：

| A列：カテゴリ | B列：問題 | C列：解答 |
| :--- | :--- | :--- |
| 色覚の多様性 | 日本人男性で、P型とD型の色覚を持つ人の割合は？ | 約5%（約20人に1人） |
| 加齢と見え方 | 水晶体が白濁して光が散乱し、かすみやまぶしさが起きる症状は？ | 白内障 |
| PCCSカラートーンサークル | 「さえた、鮮やかな、派手な」イメージのトーンは？ | v (vivid) |

> ※「問題, 解答」の2列だけのファイルでも読み込めます（その場合カテゴリは「未分類」になります）。

### アプリへの読み込み方（3通り）
1. **ファイル選択（おすすめ）**  
   右上の **「ファイル選択」** ボタンから `.xlsx` または `.csv` ファイルを選びます。  
   - **💡 便利な「🔄 再読込」機能（Chrome / Edge）**  
     1回ファイルを選択すると、右上に **`🔄 再読込 (ファイル名)`** ボタンが現れます。以降は Excel で問題を追記・修正して上書き保存したあと、**`🔄 再読込` ボタンを押すだけ**で最新の内容がすぐに反映されます！
2. **ドラッグ＆ドロップ**  
   開いているブラウザ画面に `.xlsx` または `.csv` ファイルを直接ドロップします。
3. **コピペで貼り付け**  
   Excel や Googleスプレッドシートのセル範囲をコピー（`Cmd+C` / `Ctrl+C`）し、右上の **「貼り付け」** ボタンを押して貼り付けるだけでも取り込めます。

※ 一度読み込んだ問題データはブラウザ内に自動保存されるため、ブラウザを閉じても次回そのまま続きから学習できます。
