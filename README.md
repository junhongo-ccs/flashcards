# Excel de 暗記カード

Excel（または CSV）に「カテゴリ・問題・解答」を書くだけで、そのまま暗記カードとして学習できるWebアプリです。  
資格試験の弱点対策など、自分だけの問題集づくりに使えます。  
サーバー不要で、`anki.html` をブラウザで開くだけでそのまま使えます。

---

## 1. はじめ方（一番かんたんな使い方）

1. フォルダ内の **`anki.html`** をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開きます。
2. 自分の問題データ（Excel または CSV）を読み込ませて暗記カードとして学習できます。

---

## 2. 基本の操作方法

### カードをめくる・移動する
| 操作 | マウス / タッチ | キーボード |
| :--- | :--- | :--- |
| **解答を表示する** | カード内の「解答を表示」ボタン、カード右側の `>` ボタン | `→`（右矢印キー） |
| **次の問題へ進む**（解答表示後） | カード右側の `>` ボタン | `→`（右矢印キー） |
| **前の問題へ戻る**（解答は隠れた状態） | カード左側の `<` ボタン | `←`（左矢印キー） |

### 画面上部のメニュー
- **ヘッダー（右上）**：`再読込`・`QAファイル選択`（読み込み方は下記「3.」参照）。
- **カテゴリ選択（左）**：「すべてのカテゴリ」または特定の分野だけに絞り込んで出題できます。
- **`QA順 [ 設定のまま | シャッフル ]` スイッチ（右）**：「設定のまま」は Excel に書いた順で出題します。「シャッフル」にすると、カテゴリの並びはそのままで各カテゴリ内の問題の順番をシャッフルします（押すたびにシャッフルし直し）。
- **`[ 問題 | QA一覧 ]` スイッチ（右）**：
  - **問題**：1問ずつ暗記カード形式で学習する通常モードです。
  - **QA一覧**：すべての問題と解答を一覧で確認するモードです（資料として見られるよう、シャッフル中でも常に元の順で表示）。一覧のカードをクリックすると、その問題のカード表示へ直接ジャンプします。

---

## 3. 自分の問題データ（Excel / CSV）を作って読み込む方法

自分が覚えたい問題だけをまとめた Excel（`.xlsx`）や CSV（`.csv`）を読み込ませることができます。

### 同梱の `my-weakness.xlsx` を使う
色彩検定UC級の問題をまとめた **`my-weakness.xlsx`** を同梱しています。
- **そのまま使う**：「QAファイル選択」で `my-weakness.xlsx` を選ぶだけで学習を始められます。
- **カスタマイズして使う**：Excel で開いて **別名で新規保存**（例：`my-questions.xlsx`）し、問題を追加・修正・削除して自分専用の問題集にできます。

### Excel / CSV の作り方（3列構成）
1行目をヘッダーにして、以下の3列で入力してください（1行＝1問）。例：

| A列：カテゴリ | B列：問題 | C列：解答 |
| :--- | :--- | :--- |
| 色覚の多様性 | 日本人男性で、P型とD型の色覚を持つ人の割合は？ | 約5%（約20人に1人） |
| 加齢と見え方 | 水晶体が白濁して光が散乱し、かすみやまぶしさが起きる症状は？ | 白内障 |
| PCCSカラートーンサークル | 「さえた、鮮やかな、派手な」イメージのトーンは？ | v (vivid) |

> ※「問題, 解答」の2列だけのファイルでも読み込めます（その場合カテゴリは「未分類」になります）。

### アプリへの読み込み方（2通り）
1. **QAファイル選択（おすすめ）**  
   右上の **「QAファイル選択」** ボタンから `.xlsx` または `.csv` ファイルを選びます。  
   - **💡 便利な「再読込」機能（Chrome / Edge）**  
     1回ファイルを選択すると、右上に **`再読込 (ファイル名)`** ボタンが現れます。以降は Excel で問題を追記・修正して上書き保存したあと、**`再読込` ボタンを押すだけ**で最新の内容がすぐに反映されます！
2. **ドラッグ＆ドロップ**  
   開いているブラウザ画面に `.xlsx` または `.csv` ファイルを直接ドロップします。

※ 一度読み込んだ問題データはブラウザ内に自動保存されるため、ブラウザを閉じても次回そのまま続きから学習できます。
